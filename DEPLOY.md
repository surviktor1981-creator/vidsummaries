# Запуск в облаке

Бот держит постоянное соединение с Telegram, поэтому ему нужен процесс, который
работает всегда. Подойдёт самый дешёвый VPS: **1 ядро, 1 ГБ памяти, 10 ГБ
диска** — этого достаточно с запасом. Публичный домен и белый IP не нужны:
бот сам ходит в Telegram, входящих соединений не принимает.

Всё ниже — для Ubuntu 22.04 или 24.04. Провайдер значения не имеет.

## Что понадобится

- Токен бота от [@BotFather](https://t.me/BotFather)
- Ключ [Anthropic](https://console.anthropic.com) и ненулевой баланс
- Ваш Telegram ID от [@userinfobot](https://t.me/userinfobot)
- Сервер и доступ к нему по SSH

## Шаг 1. Подключиться к серверу

```bash
ssh root@АДРЕС_СЕРВЕРА
```

## Шаг 2. Поставить Docker

```bash
curl -fsSL https://get.docker.com | sh
```

Проверка — команда должна напечатать версию:

```bash
docker compose version
```

## Шаг 3. Забрать код

```bash
git clone -b claude/telegram-video-summary-format-cbcku9 \
  https://github.com/surviktor1981-creator/vidsummaries.git
cd vidsummaries
```

Если репозиторий приватный, `git clone` попросит пароль. Секретов в репозитории
нет — `.env` не коммитится, — поэтому проще всего сделать его публичным в
настройках GitHub. Либо загрузите файлы на сервер вручную: `scp -r . root@АДРЕС:~/vidsummaries`.

## Шаг 4. Заполнить .env

```bash
cp .env.example .env
nano .env
```

Заполните три строки:

```
TELEGRAM_BOT_TOKEN=8123456789:AAF...
ANTHROPIC_API_KEY=sk-ant-api03-...
ALLOWED_USER_IDS=123456789
```

`ALLOWED_USER_IDS` не оставляйте пустым: иначе ботом сможет пользоваться любой,
кто узнает его имя, — за ваш счёт.

Сохранить в nano: `Ctrl+O`, `Enter`, затем `Ctrl+X`.

## Шаг 5. Запустить

```bash
docker compose up -d --build
```

Первая сборка занимает пару минут. Дальше бот стартует сам при перезагрузке
сервера — за это отвечает `restart: unless-stopped`.

## Шаг 6. Проверить

```bash
docker compose logs -f
```

Должна появиться строка вида `Бот запущен: @ваш_бот, модель claude-opus-5`.
Выйти из просмотра логов — `Ctrl+C`, бот при этом продолжает работать.

Теперь напишите боту в Telegram ссылку на видео. Если что-то пойдёт не так,
ошибка будет и в чате, и в логах.

---

## Обновление

```bash
cd vidsummaries
git pull
docker compose up -d --build
```

База с транскриптами лежит в `./data` и переживает пересборку.

## Когда YouTube попросит подтвердить, что вы не бот

С серверных адресов это случается регулярно. Лечится файлом cookies от
залогиненного аккаунта.

1. Установите в браузере расширение для экспорта cookies в формате Netscape
   (ищется как «Get cookies.txt»)
2. Откройте youtube.com залогиненным и выгрузите `cookies.txt`
3. Положите файл на сервер в `~/vidsummaries/data/cookies.txt`:
   ```bash
   scp cookies.txt root@АДРЕС:~/vidsummaries/data/cookies.txt
   ```
4. Добавьте в `.env` строку `COOKIES_FILE=/data/cookies.txt`
5. `docker compose up -d`

Файл должен лежать именно в `data/` — yt-dlp обновляет cookies по ходу работы,
и этот каталог единственный записываемый внутри контейнера.

Заводите для этого отдельный аккаунт Google, а не основной: cookies дают полный
доступ к аккаунту, а лежат они на сервере.

Если cookies не помогли — обычно значит, что IP сервера в списке подозрительных
целиком. Тогда либо прокси через `YTDLP_PROXY` в `.env`, либо сервер у другого
провайдера.

## Если что-то не работает

| Симптом | Причина и что делать |
|---|---|
| Бот молчит на любые сообщения | Неверный `TELEGRAM_BOT_TOKEN`, либо ваш ID не в `ALLOWED_USER_IDS`. Смотрите `docker compose logs` |
| «Что-то пошло не так при разборе» | Чаще всего пустой баланс Anthropic. Проверьте Billing в консоли |
| `credit balance is too low` в логах | То же самое — пополните баланс |
| «Не удалось получить видео» | Видео приватное, удалено или требует авторизации |
| Просит подтвердить, что не бот | См. раздел про cookies выше |
| Контейнер перезапускается по кругу | `docker compose logs --tail 50` покажет причину; обычно синтаксис в `.env` |

Полезные команды:

```bash
docker compose ps          # работает ли
docker compose logs --tail 100
docker compose restart
docker compose down        # остановить
```

## Сколько это стоит

- Сервер: $4–6 в месяц
- Anthropic: порядка $0.2–0.4 за час видео на Opus 5, втрое дешевле на

## Распознавание речи

Изредка у видео нет ни субтитров автора, ни автоматических. Тогда нужно
распознавание — пакет уже в образе, включается одной строкой в `.env`:

```
ASR_BACKEND=faster-whisper
```

Затем `docker compose up -d`. При первом таком видео модель скачается (около
145 МБ для `base`) в `./data/models` и переживёт последующие пересборки.

**Сколько ждать.** Распознавание идёт медленнее реального времени. Порядок для
модели `base` с `int8`:

| Ядер | Час звука обрабатывается за |
|---|---|
| 1 | ~60 мин |
| 2 | ~30 мин |
| 4 | ~20 мин |

Бот пишет оценку в чат и продолжает в фоне — чат можно закрыть, саммари придёт
само. Видео длиннее `ASR_MAX_DURATION` (по умолчанию 1.5 часа) отклоняются
сразу: иначе одно длинное видео заняло бы бота на полдня.

**Выбор модели** — `WHISPER_MODEL` в `.env`:

| Модель | Размер | Скорость | Когда брать |
|---|---|---|---|
| `tiny` | 75 МБ | самая быстрая | только разобрать смысл, много ошибок в терминах |
| `base` | 145 МБ | вдвое медленнее `tiny` | по умолчанию, разумный компромисс |
| `small` | 460 МБ | ещё в 2,5 раза медленнее | когда важна точность имён и терминов |
| `medium` | 1,5 ГБ | втрое медленнее `small` | нужен сервер от 4 ГБ памяти |

**Памяти** нужно ориентировочно: `base` — 1 ГБ свободной, `small` — 1,5 ГБ,
`medium` — 3 ГБ. Проверить, что есть на сервере:

```bash
free -h && nproc
```

Если памяти в обрез, контейнер убьёт OOM-killer прямо во время распознавания —
в логах будет `Killed`. Тогда берите модель меньше или тариф больше.
