# vidsum

Телеграм-бот: кидаете ссылку на видео — получаете текстовое саммари, из которого
не выпали цифры, имена и оговорки.

```
Вы:  https://youtu.be/xxxxxxx
Бот: 🎬 Название · Канал · 47 мин · интервью

     📌 ВЕРДИКТ
     ...
     🔑 ТЕЗИСЫ / 🕐 ПО ТАЙМКОДАМ / 🔢 ФАКТУРА / ⚠️ ОГОВОРКИ

     [📄 Подробно] [⚡ Тезисы] [❓ Спросить по видео]
```

## Формат саммари

Обычное саммари теряет не объём, а конкретику: модель по умолчанию пишет *о чём
говорили* вместо *что именно утверждали*. Поэтому формат разложен на секции, и
под фактуру выделены отдельные поля — [`vidsum/models.py`](vidsum/models.py)
задаёт схему, которую модель обязана заполнить целиком.

| Секция | Что в ней | Зачем |
|---|---|---|
| Вердикт | 2–3 предложения + «смотреть или нет» | Единственное, что читают в большинстве случаев |
| Тезисы | 5–9 утверждений с основанием и спикером | **Тезис, а не тема**: не «автор про рынок», а «автор ждёт −20% к Q3, потому что…» |
| По таймкодам | Главы с кликабельными ссылками, пропускаемые помечены | Пересмотреть нужный кусок вместо всего видео |
| Фактура | Цифры, имена, инструменты, термины, ссылки | Отдельные поля — именно это заставляет модель их вытащить, а не растворить в прозе |
| Практика | Шаги, команды, чеклист | Если в видео есть, что применить |
| Оговорки | Условия применимости, непроверенные заявления | Теряется чаще всего и стоит дороже всего |
| Разногласия | Кто с кем не согласился | В интервью это и есть суть; усреднять диалог нельзя |
| Реклама | Таймкоды интеграций | Чтобы не путать с содержанием |
| Неразборчиво | Места, где ASR сбоил | Честнее, чем додумывать |

Акценты подстраиваются под тип видео (лекция / интервью / туториал / новости /
обзор / стрим) — правила в [`vidsum/prompts.py`](vidsum/prompts.py).

Телеграм ограничивает сообщение 4096 символами, поэтому короткая версия
собирается по приоритету и подрезается снизу; полная уходит `.md`-файлом по
кнопке **Подробно**.

## Установка

```bash
git clone <репозиторий> && cd vidsummaries
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt

cp .env.example .env   # заполните TELEGRAM_BOT_TOKEN и ANTHROPIC_API_KEY
```

Токен бота — у [@BotFather](https://t.me/BotFather), ключ Anthropic — в
[консоли](https://console.anthropic.com).

Для личного бота укажите свой Telegram user id в `ALLOWED_USER_IDS` — иначе
ботом сможет пользоваться любой, кто узнает его имя, за ваш счёт.

## Запуск

Круглосуточно в облаке, без привязки к вашему компьютеру — **[DEPLOY.md](DEPLOY.md)**:
дешёвый VPS, `docker compose up -d`, автоперезапуск.

Локально, чтобы попробовать:

```bash
python bot.py
```

Проверить пайплайн без Telegram:

```bash
python cli.py https://youtu.be/xxxxxxx              # саммари в консоль + full.md
python cli.py https://youtu.be/xxxxxxx --ask "какие цифры он называл?"
python cli.py https://youtu.be/xxxxxxx --dump-transcript t.txt   # только расшифровка
python cli.py --subs local.vtt --title "Название"   # на локальном файле субтитров
```

## Как это работает

```
ссылка ──yt-dlp──> метаданные + субтитры ──> сегменты с таймкодами
                          │ (если субтитров нет)
                          └──> локальный ASR ──> сегменты
                                                    │
                        Claude + схема формата <────┘
                                │
              короткое сообщение + полная версия + Q&A по транскрипту
```

Откуда берётся текст, по убыванию предпочтения: субтитры автора → автосубтитры
→ локальное распознавание. Языки — `ru`, `en`, затем любой доступный.
Автосубтитры приходят «бегущей строкой» с повторами — они склеиваются
(`vidsum/transcript.py`).

Видео короче ~3 часов разбираются одним проходом. Длиннее — режутся на окна с
перехлёстом: по каждому окну делается выжимка, потом всё собирается в один
формат. Порог настраивается через `max_single_pass_tokens` в `vidsum/config.py`.

Транскрипт сохраняется в SQLite, поэтому кнопка **Спросить** отвечает по
содержанию видео без перекачивания, а повторная ссылка возвращает готовое
саммари мгновенно (кэш на 30 дней).

## Стоимость

Порядок величины на Claude Opus 5 — **$0.2–0.4 за час видео**. На
`claude-sonnet-5` (`ANTHROPIC_MODEL=claude-sonnet-5`) примерно втрое дешевле,
ценой чуть менее точных формулировок тезисов. `EFFORT=medium` тоже заметно
снижает расход. Точная цифра зависит от плотности речи.

## Настройки

Все — через `.env`, см. [`.env.example`](.env.example). Основное:

| Переменная | По умолчанию | Смысл |
|---|---|---|
| `SUMMARY_LANG` | `ru` | Язык саммари независимо от языка видео |
| `ANTHROPIC_MODEL` | `claude-opus-5` | Модель |
| `EFFORT` | `high` | Глубина разбора: `low`…`max` |
| `ALLOWED_USER_IDS` | пусто | Белый список Telegram id |
| `ASR_BACKEND` | `off` | `faster-whisper` — распознавание, когда субтитров нет |

## Если у видео нет субтитров

Включите локальное распознавание:

```bash
pip install faster-whisper      # плюс ffmpeg в системе
# в .env:  ASR_BACKEND=faster-whisper   WHISPER_MODEL=small
```

Оно медленное (несколько минут на час видео на CPU) и качество ниже субтитров,
зато не зависит от их наличия.

## Если YouTube просит подтвердить, что вы не бот

Такое бывает при запуске с серверного IP. Лечится файлом cookies: положите его
рядом и укажите `COOKIES_FILE` в `.env`, в тяжёлых случаях — `YTDLP_PROXY`.
Подробно — в [DEPLOY.md](DEPLOY.md#когда-youtube-попросит-подтвердить-что-вы-не-бот).

## Другие источники

Скачивание идёт через yt-dlp, который поддерживает [сотни
сайтов](https://github.com/yt-dlp/yt-dlp/blob/master/supportedsites.md), и код
не завязан на YouTube: ссылка на другой сайт пойдёт тем же путём, а таймкод-
ссылки соберутся через `?t=`. Но отлаживалось всё на YouTube — на Rutube и VK
возможны сюрпризы с извлечением субтитров.

## Тесты

```bash
pip install pytest
python -m pytest tests/ -q
```

38 тестов: парсинг субтитров и склейка автосубтитров, нарезка длинных видео,
выбор языковой дорожки, форма запроса к API (схема формата, кэширование
транскрипта, ветка map-reduce), отрисовка и лимит Telegram, круговой обход
хранилища. Сеть не нужна — вызовы модели идут через мок-транспорт.

**Что не проверено вживую:** загрузка с YouTube и реальные ответы модели — в
среде разработки не было ни доступа к youtube.com, ни ключа Anthropic. Первый
запуск на вашей машине — это и есть первая живая проверка; начните с
`python cli.py <ссылка> -v`.
